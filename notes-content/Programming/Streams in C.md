printf writes to stdout
scanf reads from stdin referring to the keyboard by default
fprintf writes to a specified output stream
  
“<“ : input redirection
“>” : output redirection

limitation: only one file can be used for i/o redirection
- we require using c files to redirect from more than one file.

**$ sort < names.cat > students.txt**

**The program being run is ____________. Standard input is redirected to _________. Standard output is redirected to _________.**

Ans: sort, names.cat, students.txt
