# Long Term Memory

Long-term memory (LTM) is the memory store that retains information over extended periods — from hours to a lifetime — in contrast to the limited, transient capacity of [[Working Memory]].

- **Declarative (explicit)** memory: facts and events that can be consciously recalled.
- **Procedural (implicit)** memory: skills and habits — see [[Procedural memory]] and [[Habits]].
- Encoding into LTM is improved by organizing information into meaningful units ([[Chunking]]) and by matching the conditions of retrieval to those of encoding ([[Transfer Appropriate Processing]]).
