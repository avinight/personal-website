# Relevance

**Relevance realization** is the cognitive process by which an agent zeroes in on what matters in a given situation while ignoring the overwhelming majority of information that does not. Because the set of potentially relevant facts, actions, and associations is effectively infinite, relevance cannot be solved by checking items against a fixed rulebook — doing so triggers a [[Combinatorial Explosion]] (and the [[The Frame Problem]] in GOFAI).

- It is **dynamic and self-organizing**: the agent continuously re-prioritizes what is worth attending to as the context changes, rather than computing relevance once.
- It is tightly bound to [[Salience]] (what stands out), [[Working Memory]] (a higher-order relevance filter), and the way [[Memory]] is applied to the current context.
- It underwrites [[Insight]], [[Intuition]], and — when it breaks down at the level of a whole worldview — the [[Meaning Crisis]].
