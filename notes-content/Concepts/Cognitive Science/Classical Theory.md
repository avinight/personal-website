# Classical Theory

[[Presuppositions]]
Why is it classical?

- Goes back to classical greek (Aristotle)
- Most generally shared conception (correct theory?)
    - Most people believe concepts work the way classical theory says they do

*Concept*: is a mental definition

Most definitions in a dictionary aren't definitions, they're descriptions

Logical → Like Einsteinian relativity

Concepts → Like quantum mechanics

Definition in a classical sense: A set of features (didn't we disprove the existence of features) that are individually (on their own) necessary and jointly (as a set) sufficient.

Oxygen is necessary for a fire

It's not enough for a fire

Flamethrowers are sufficient for a fire

It's not necessary for a fire

### 6 Claims of Classical Theory

1. A concept can be conjunctive list of attributes
2. These features are atomic or primitive (lego model of meaning)
    1. features that cannot be divided any further 
    2. $\frac{1}{2^x}$
3. Each feature is individually [[Necessity and Sufficiency#^c8a579|necessary]] and jointly [[Sufficiency|sufficient]]
4. What's a member of that category for the concept is clearly defined, there are clear boundaries. EXHAUSTIVE DOMINATION 
    
    [[Exhaustive Domination]]
    
    1. Anything missing one of those features falls outside and doesn't belong to that category
    2. All members of the concept's categories are equally representative. All are equally good triangles. Membership is solely based on sharing necessary and sufficient features, something they all equally share.
5. If organized into a taxonomy, then subordinate definition includes superordinate definition
    1. Cat → Animal → Living Thing
    2. Deductive necessity
        1. If cat → then animal → then living thing necessarily
6. Tells you decision procedure from selecting from the properties
    1. Only pay attention to essential properties
    2. Essences: Set of necessary and sufficient properties
        1. Don't pay attention to all the properties, only pay attention to the essential features
        2. I think this is homuncular because categories aren't logically presupposed by features that we deem essential. All features are essential features!
            1. We're explaining concepts using concepts!
            2. We choose the set of primitives, which is homuncular!
            3. Still doesn't explain how we know a primitive is a primitive and how many there are?
    3. Categorization on the basis of essential features
        1. They are defined based on necessity and sufficiency (LOGIC)
        2. Explains the productivity of new concepts (creativity)
        3. Productivity of language explained in terms of compositionality
            1. Composed of a primitive set of necessary and sufficient features
