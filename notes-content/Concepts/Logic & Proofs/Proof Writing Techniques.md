# Proof Writing Techniques

- Multiply both sides to get what you want

- Multiply by 1, Add a zero

- Use the inequality or equality to your advantage
	- Inequalities can be added or substracted
	- Inequalities can also be used with equalities
		- $3x \leq 4 \implies 3x(2) \leq 4(2)$

- Manipulate any numbers if you can.
	- $8x^4 =7x^4 + x^4$
	- $1 = 2 - 1$

- Concrete numbers do not need any further explanation

- You can use the assumption multiple times
	- $n > 3 \implies n^3 > 9$, by multiplying the assumption inequality by itself.

- Same base exponents are equivalent

- For the induction step, it is advisable to use $k$ instead of $n$
