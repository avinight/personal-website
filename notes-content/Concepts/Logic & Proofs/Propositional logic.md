# Propositional Logic

[[Proposition]]
A proposition is True or False statement.

There is no variable or unknown.
If there is a variable, then it is a [[Predicate (mathematical logic) | predicate]] that depends on one (or more) variables/unknowns ("open proposition")

Propositional Variable: p, q, r

Propositional Operators
- [[Logical Disjunction]]
- [[Negation]], [[Logical Conjunction]], [[Logical Biconditional]]

[[Material Conditional]]

$\implies$ is a natural connective to use with $\forall$ [[Universal Proof]]
- Using $\land$ as the main connective with $\forall$ led to an overly strong statement

$\land$ is a natural connective to use with $\exists$ [[Existential Proof]]
- Using $\implies$ with $\exists$ usually leads to a very weak statement indeed.

Deductions we don't need to provide justification
- Any deduction whose truth can be verified using a calculator, and any comparison, divisibility and [[Floor and Ceiling functions]] operation on concrete numbers.
- Any basic manipulation of an equality or inequality to get another value equality or inequality.
