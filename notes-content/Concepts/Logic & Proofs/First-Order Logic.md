# First-Order Logic

aka. Predicate Logic, Quantificational Logic, First-Order Predicate Calculus

Deals with definitions using quanitifiers

Predicate operators
- $\forall$ universal quantifier "for all"
- $\exists$ existential quantifier "there exists"

CSC165 syntax
$\forall x \in D, P(x)$
$\exists x \in D, P(x)$
- Commas are "fixed" = always using this notation
- P(x) is a [[Predicate (mathematical logic) | predicate]] statement that depends on x.

A logical statement in predicate form does not depend on its variables. It is a statement about the set, not the variable.

Examples
$\forall x \in \mathbb{R}, x > 165$
$\forall z \in \mathbb{R}, z > 165$
- These two statements are exactly the same.
