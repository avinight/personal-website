Synonymous with Probability Model, Probability Distribution
```ad-note 
title: Definition (Probability Function)

Given a random experiment with discrete sample space $\Omega$, a probability function P is a function on Ω with the following properties:

1. $$P(\omega) \geq 0, \forall \omega \in \Omega$$
2. $$\sum_{\omega \in \Omega}P(\omega) = 1$$
3. For all events $A \subseteq \Omega$ $$P(A) = \sum_{\omega \in A}P(\omega)$$
```
