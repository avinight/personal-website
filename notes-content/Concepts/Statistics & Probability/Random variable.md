<u>Def</u>: A random variable is a real valued function that assigns a numerical value to each event in the sample space $\Omega$ arising from a random experiment
$$X: \Omega \to \mathbb{R}$$
such that, $\forall \omega \in \Omega, X(\omega) = x \in \mathbb{R}$.
