# Probability as Relative Frequency

The long-run relative frequency of an event A will approach the probability of event A. In cases where the sample space consists of equally likely elements, we can find this probability by calculating the relative frequency of A in $\Omega$.

$$P(A) = \frac{ \text{\# outcomes in }A}{ \text{Total \# of possible outcomes in random experiment}} = \frac{n(A)}{n(\Omega)}$$
This is valid only if each element in $\Omega$ is equally likely.
