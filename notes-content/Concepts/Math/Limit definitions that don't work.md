Definitions that don't work
$\fa \epsilon >0, \ex \delta > 0, (\fa x), |f(x) - L| < \epsilon \implies 0 < |x - a| <\delta$
- For the converse, the limit can have multiple intervals that approach it outside delta.

$\ex \delta > 0, \fa \epsilon >0, (\fa x), 0 < |x - a| <\delta \implies |f(x) - L| < \epsilon$
- Fixing an interval will have shooters that miss for smaller epsilon.

$\fa \delta > 0, \ex \epsilon >0, (\fa x), 0 < |x - a| <\delta \implies |f(x) - L| < \epsilon$
