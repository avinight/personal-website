```ad-note
title: Theorem
color: 0, 236, 220

If $f$ is continuous on $[a, b]$, then $f$ is bounded above on $[a, b]$, that is, there is some number $N$ such that $f(x) < N$ for all $x$ in $[a,b]$.
```
![[BAT.png]]
Counterexample:
$f(x) = \begin{cases} \frac{1}{x} & x \neq 0 \\ 1 & x = 0 \end{cases}$
