# Logarithm

Product Rule
$$\log_b(x \cdot y) = \log_b(x) + \log_b(y)$$

Quotient Rule
$$\log_b(\frac{x}{y}) = \log_b(x) - \log_b(y)$$

Power Rule
$$\log_b(x^y) = y \cdot \log_b(x)$$

Base Switch Rule
$$\log_b(c) = \frac{1}{\log_c(b)}$$

Base Change Rule
$$\log_b(x) = \frac{\log_c(x)}{\log_c(b)}$$

Derivative
$$f(x) = \log_b(x) \implies f'(x) = \frac{1}{(x \ln(b))}$$

Integral
$$\int \log_b(x) dx = x \cdot\left(\frac{\log_b(x) - 1}{\ln(b)}\right) + C$$

How do we derive the logarithm?
$\frac{1}{x}$ is missing
Let $\ds F(x) = \int_1^{x} \frac{1}{t} dt$
$F'(x) = \frac{1}{x}$
$\ds \log x = \int{1}{x}\frac{1}{t}dt$
$\ds (\log x)' = \frac{1}{x}$

$\log(1) = 0$
$\ds \log(xy)' = \frac{1}{xy}y = \frac{1}{x}$
$\ds \log(xy) = \log(x) + c$

put $x = 1$
$\log(y) = \log(1) + c$

$\ds \log(xy) = \log(x) + \log(y)$
