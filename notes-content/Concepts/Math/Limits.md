<u>Provisional Definition</u>: The function f approaches the limit L near a, if we can make f(x) as close as we like to L by requiring that x be sufficiently close to, but unequal to, a.

<u>Intuition</u>: For every target box that keeps getting smaller, I can find shooters that will never miss that are not the point a.
```ad-note
title: Definition
<u>Def:</u>  Formal Definition of Limit
$$\forall \epsilon > 0, \exists \delta > 0, (\forall x \in \mathbb{R}), 0 < |x-a|<\delta \implies |f(x) - L| < \epsilon $$
```
```ad-note
title: Notation
$$\ds \lim_{x \to a} f(x) = L$$
```
