```ad-note
title: Theorem
color: 0, 236, 220

If $f$ is continuous on $[a, b]$ and $f(a) < c < f(b)$, then there is some $x$ in $[a, b]$ such that $f(x) = c$
```

```ad-note
title: Proof
color: 255, 0, 0

Let $g = f — c$. Then $g$ is continuous, and $g(a) < 0 < g(b)$. By [[Intermediate Value Theorem]], there is some $x$ in $[a,b]$ such that $g(x) = 0$. But this means that $f(x) = c$
```
