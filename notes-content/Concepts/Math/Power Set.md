# Power Set

A power set is the set of all subsets of a set.
$$\mathcal{P}(A) = \{X \divides X \subseteq A\}$$

The power set of a set with one element (general formula)
$$ \mathcal{P}(\{x\}) = \{\emptyset, \{x\}\}$$
