title: Theorem
color: 0, 236, 220

$$\begin{align}
P(\bigcup_{i = 1}^n A_i) &= \sum_{i = 1}^n P(A_i) - \sum_{i < j}P(A_i \cap A_j) + \cdots \\
&+ (-1)^{r + 1} \sum_{i_1 < i_2 < \ldots < i_r} P(A_{i_1} \cap A_{i_2} \cap \ldots \cap A_{i_n}) + \cdots \\
&+ (-1)^{n + 1} P(A_{i_1} \cap A_{i_2} \cap \ldots \cap A_{i_n})
\end{align}
$$

$r$ is the number of elements in some subset
