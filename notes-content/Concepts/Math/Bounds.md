```ad-note 
title: Definition

<u>Def:</u> A <u>lower bound</u> for A is an element $l \in F$ such that $l \leq a$ for all $a \in A$.

<u>Def:</u> A <u>greatest lower bound</u> for A is an element $l_0 \in F$ such that $l_0$ is a lower bound.

```
