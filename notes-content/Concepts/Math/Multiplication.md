# Multiplication

Value of i always increases by +1 between the first and last values

Pi Notation

---

We define the empty product with identity value 1 as:
$$ \forall j, k \in \mathbb{Z}, j > k \implies \prod_{i = j}^{k} f(i) = 1$$

- It is a generalization of properties
- Properties work with this value
- We don't need to make exceptions
