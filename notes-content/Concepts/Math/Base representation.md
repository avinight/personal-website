# Base representation

<a href=https://en.wikipedia.org/wiki/Two%27s_complement> Two's Complement </a>

How do we represent numbers in base form?
- For $k \in \mathbb{Z}^+$ and $d_0, d_1, \cdots, d_{k-1} \in \{0, 1, \cdots, b - 1\}$, the expression, $$(d_{k-1}d_{k-2}\cdots d_1 d_0)_b$$ represents the number,
	$$ x = \sum_{i=0}^{k-1}d_i \times b^i$$
