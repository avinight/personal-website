# Successor function

A function S(x) for any $x \in \mathbb{N}$ where S(x) = x + 1

Three ideas about successor:
1. 'next to' the number, the idea of an 'ordering relation' between the numbers
2. there is nothing in between the number and its successor (natural numbers)
3. this successor is 'unique'; that is, only one successor can exist for each given number
