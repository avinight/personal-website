# Linear Transformations

 Some Theorems
 - If $T : \mathbb{R}^n \rightarrow \mathbb{R}^n$ is a linear transformation, then $T(\vec{0}) = 0$.
 - If $T : \mathbb{R}^n \rightarrow \mathbb{R}^n$ is a linear transformation, then T takes lines to lines (or points)
 - If $T : \mathbb{R}^n \rightarrow \mathbb{R}^n$ is a linear transformation, then T takes parallel lines to parallel lines (or points)
	 - Parallel lines do not stay parallel under all linear transformations.
	 - The zero vector takes parallel lines to a single point.
 - If $T : \mathbb{R}^n \rightarrow \mathbb{R}^n$ is a linear transformation, then T takes subspaces to subspaces.
	 - The image of a subspace under a linear transformation is a subspace.

[[Inverses and Invertibility]]
The matrix for a transformation is invertible if and only if the transformation is invertible. This is not affected by the choice of basis.

All matrix transformations are linear transformations and most linear transformations are matrix transformations

- Every transformation from R^n to R^m cannot be represented by a matrix.
- Every "linear" transformation from R^n to R^m can be represented by a matrix.
