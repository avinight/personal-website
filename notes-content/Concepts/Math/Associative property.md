# Associativity

```ad-note
title: Definition
Associative law for addition
<u>Def:</u> a + (b + c) = (a + b) + c 
for numbers a, b, c

Associative law for multiplication
<u>Def:</u> $a \cdot (b \cdot c) = (a \cdot b) \cdot c$ 
for numbers a, b, c

```
