# Span

Span
- The set of all linear combinations of vectors in V.
- $\text{span}V = \{ \vec{v} : \vec{v} = \alpha_{1} \vec{v}_{1} + ... + \alpha_{n} \vec{v}_{n} \text{ for some } \vec{v}_{1}, ... , \vec{v}_{n} \text{ and scalars } \alpha_{1}, ... ,\alpha_{n} \}$
- $\text{span}\{\} = \{\vec{0}\}$
All points that can be reached by a linear combination of $\vec{v}_1$,...,$\vec{v}_n$.

All spans contain all linear combinations

All linear combinations is like saying a linear combination of vectors for some scalars, which could be false.

There are not exactly n elements in S because n + 1 is an element of S.

Let V be a vector space and let S be any subset of V. Then Span(S) is a subspace of V.

Example.
- $S_1 = \{\sin^2,\cos^2\}, S_2 = \{1, \sin^2,\cos^2\}$
	S_1 = S_2 since Sp(S_2) is a subspace and Sp(S_1) is also a subspace and every element is an element of the other set.
