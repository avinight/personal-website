```ad-note
title: Theorem
color: 0, 236, 220

If $f$ is continuous at $a$, then there is a number $\delta > 0$ such that $f$ is bounded above on the interval $(a - \delta, a + \delta)$
```

```ad-note
title: Proof
color: 255, 0, 0

Since $\lim_{x \to a} f(x) = f(a)$, for every $\epsilon > 0$, there is a $\delta > 0$ such that, for all $x$,
$$|x - a| < \delta \implies |f(x) - f(a)| < \epsilon$$

It is only necessary to apply this statement to a particular $\epsilon$, so that on the interval $(a - \delta, a + \delta)$, $f$ is bounded above.
```
