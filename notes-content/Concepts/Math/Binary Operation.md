# Binary Operation
```ad-note
title: Definition
<u>Def:</u> A binary operation on a set S is a rule for combining two elements of S to produce a third element of S. More formally, a binary operation is a mapping 
$$S \times S \rightarrow S$$
[[Cartesian Product]] of 2 sets.
```
If the binary operation is called, say ∗, we usually write $s_1 ∗ s_2$ for the third element of S obtained by applying the  
operation to the pair of elements $s1, s2$ in S

Let ∗ be a binary operation on a set S.
1. We say ∗ is commutative on S if for all s1 and s2 in S we have s1 ∗ s2 = s2 ∗ s1.
2. We say ∗ is associative on S if for all s1, s2 and s3 in S we have (s1 ∗ s2) ∗ s3 = s1 ∗ (s2 ∗ s3).
3. We say ∗ has an identity in S if there exists an element e in S such that r ∗ e = e ∗ r = r for all r ∈ S.
4. Suppose ∗has an identity e in S. We say r in S is invertible if there exists another element s in S such that r ∗ s = s ∗ r = e. The element s is called an inverse of r.
