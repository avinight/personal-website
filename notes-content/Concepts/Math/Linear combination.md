# Linear combination

(1.3.1) Definition
A) A linear combination of vectors in S is any sum $$a_1x_1 + \cdots + a_nx_n$$where $a_i \in \mathbb{R}$ and the $x_i \in S$.

B) If $S = \emptyset$ (the empty subset of V), the set of all linear combinations of vectors in $S$ is called the (linear) span of S, and denoted $\text{Span}(S)$.
If $S = \emptyset$, we define $\text{Span}(S) = {0}$

C) If $W = \text{Span}(S)$, we say S spans (or generates) W.
