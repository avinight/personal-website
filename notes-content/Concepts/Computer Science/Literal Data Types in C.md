A literal is literally a hard-coded value.

Literal Strings

```Csharp
Console.WriteLine("Hello World!");

Console.Write("Hello ");
Console.Write("World!");

// End of statement operator = semi-colon
```

Char Literal
```Csharp
Console.WriteLine('b');
```

Int Literal
```Csharp
Console.WriteLine(123);
```

Decimal Literal
```Csharp
Console.WriteLine(12.3m);
// m is a literal suffix
```

Bool Literal
```Csharp
Console.WriteLine(true);
Console.WriteLine(false);
```
