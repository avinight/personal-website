# Interfaces
An interface is a collection which can be represented by:
- actions/[[Abstract Data Types|abstract]] methods
and has no method implementation

Classes are related by 
- properties

and may extend to an interface.
and may [[Inheritance|inherit]] methods from an interface.

Similarily, interfaces may extend to interfaces.
