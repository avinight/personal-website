2D -> 1D index: `row * width + col`

Reflect: `(i, j) -> (i, width - 1 - j)
Therefore: `reflected_index = i * width + (width - 1 - j)`

Rotate: `(i, j) -> ((width - 1 - j), i)`
Therefore, `new_width = height`
so that : `rotated_index = (width - 1 - j) * height + i`
