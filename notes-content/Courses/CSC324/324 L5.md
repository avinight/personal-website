Definition (Thunk): A thunk is a function with zero arguments.
Thunks are often defined in order to be passed into a function, that will
evaluate the "expression" at some point in the future.

Definition (Free identifier): A free identifier is an identifier within a
function body that:
• Is not a parameter to the function
• Is not bound in a local let-expression

Definition (Closure): A function with a free identifier is said to close
over that identifier, and we say that the function in question is a closure.

identifers)
