Lambda calculus

```# Pen-and-Paper
<expr> = IDENTIFIER
| "(" "λ" IDENTIFIER "." expr ")" # function abstraction
| "(" expr expr ")" # application: applies 1st to 2nd
# Python
<expr> = IDENTIFIER
| "lambda" IDENTIFIER ":" expr # abstraction
| expr "(" expr ")"
 # application
# Racket
<expr> = IDENTIFIER
| "(" "λ" "(" IDENTIFIER ")" expr ")" # abstraction
| "(" expr expr ")"
 # application
# Haskell
<expr> = IDENTIFIER
| "\" IDENTIFIER "->" expr # abstraction
| expr expr
 # application
```

Definition: An identifier is said to be referentially transparent if the identifier can
always be substituted for its definition without changing the program's behaviour.

Example: any pure function is always referentially transparent. By contrast, an
impure function like Python's datetime.now() function, are not referentially
transparent (calling it one second later will produce a different value!)
Example: an assignment, like x = x + 1, is not referentially transparent.
