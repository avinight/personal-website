# Typed Lambda Calculus

We say a term t is typeable (or well-typed) if there exists some T such that t : T.
A typing derivation is a tree of instances of the typing rules.

We can learn derive some properties of the typing rules.

Inversion

Theorem 2 (Uniqueness of types)
Each term t has at most one type.
That is, if t is typable, then its type is unique.
Moreover, there is just one derivation of this typing built from the inference rules.

(1) we can simply annotate the λ-abstraction with the intended type of its arguments;
