Q4) G is arbitrary cyclic graph, then it has at least 1 back edge in the DFS forest (u, v). Suppose also that repeated applications of source deletion results in an empty graph. We know that v isn't a source since it has an edge leading into it so it isn't deleted. But the graph is empty. Contradiction.

```
S <- {}
I[n]
for i from 1 -> n:
  for each edge in A[i]:
    u, v = A[i].edge
    I[v] += 1
for i from 1 -> n:
  if I[i] = 0, then add i to S
while S != NULL:
  node = S.dequeue
  for edge in A[node]:
    A[v] -= 1
    if A[v] = 0, add to S

for i from 1->n:
  if I[i] != 0:
    return False
```
