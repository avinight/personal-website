	- what filtering data structure and parameters best accelerate a particular workload?
		- (i) the actual time tl a filter lookup takes, 
		- (ii) the work time tw per tuple that a negative lookup identified by the filter saves later on, and 
		- (iii) the mentioned fraction 1-σof real negative lookups (regardless of false positives).

Blocking:
- Because a cache line is the unit of memory transfer and all bits are spread across the entire cache line, it can be considered optimal with regard to memory bandwidth eﬃciency.
- fewer hash bits are required per key and they therefore have improved computational eﬃciency as compared to classic Bloom filters.
