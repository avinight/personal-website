Message passing model
- Single Program Multiple Data (SPMD
	- All processes execute same code, communicate via messages
	- Technically, it does support executing different programs on each host/process

Why message passing?
- Build a parallel system from many independent nodes
- Nodes communicate over a network (interconnect)
- Partition data across nodes; compute in parallel
- When data is remote, exchange messages (send/receive)
- Enables collective computation across the cluster
- Scales out: add more nodes to grow total cores + memory
- Supports larger problems by growing data and processors together
- Tradeoff: harder to program, communication is explicit and manual
