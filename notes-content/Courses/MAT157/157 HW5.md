(ii) Suppose that 
$$\lim_{x \to 0} f(x) = c
$$
Prove that
$$\lim_{x\to0}f(x^2) = c
$$
Proof.  Suppose that
$$\fa \epsilon > 0, \ex \delta_1 > 0, \fa x, 0 < |x - 0| < \delta_1 \implies |x - c| < \epsilon
$$
Show that 
$$\fa \epsilon > 0, \ex \delta > 0, \fa x, 0 < |x - 0| < \delta \implies |x^2 - c| < \epsilon
$$
Let $\epsilon  > 0$ and choose $\delta  = \sqrt{\delta_1}$ for all $x$. Assume $0 < |x - 0| < \delta$.
Using the lemma from 1i,
$$a < b \iff a^2 < b^2
$$
we have that,
$$|x| < \delta \implies |x|^2 < \delta_1$$
And $$0 < |x| \implies 0 < |x|^2$$
And since $|x|^2 = x^2$,
$$0 < x^2 < \delta_1$$
Therefore since $x^2 > 0$, by assumption,
$$ 0< x^2 < \delta_1 \implies 0 < |x^2 - 0| <\delta_1 \implies |x^2 - c| < \epsilon$$

2) Prove that the limit
$$\lim_{x \to 7} \frac{1}{x-7}
$$ 
does not exist.

Proof. Suppose the limit exists. That is $\ex L > 0$, such that
$$\fa \epsilon > 0, \ex \delta > 0, \fa x, 0 < |x - 7| < \delta \implies | \frac{1}{x-7} - L| < \epsilon$$
Let $\epsilon = \epsilon$
Let $\delta > 0$ and choose $x$ to be any value bounded by,$$-\delta + 7 < x < \min\{\delta + 7,\frac{1}{|L| + \epsilon} + 7\}$$
Then it is clear that, 
$$-\delta + 7 < x < \delta + 7$$
and hence, 
$$0 < |x - 7| < \delta$$
It remains to show that $x$ does not satisfy $| \frac{1}{x - 7} - L| < \epsilon$
We proceed with a closer inequality using the triangle inequality. 
$$
|\frac{1}{x - 7} - L| \geq | \frac{1}{x - 7}| - |L| <\epsilon \\
$$
By proving that $x$ does not satisfy this closer inequality, we may conclude that it does not satisfy the original inequality since any value bigger than the LHS will not be smaller than $\epsilon$. Continuing further,
$$| \frac{1}{x - 7}| \geq \frac{1}{x - 7} < \epsilon + |L|
$$
$$1 < (x - 7)(\epsilon + |L|)
$$
By definition of $x$,
$$\begin{align}
1 &< (x - 7)(\epsilon + |L|)< (\frac{1}{|L| + \epsilon}+ 7 - 7)(\epsilon + |L|) \\
1 &< (x - 7)(\epsilon + |L|) < \frac{(\epsilon + |L|)}{( |L| + \epsilon)} \\
1 &< (x - 7)(\epsilon + |L|) < 1
\end{align}$$
Hence, $x$ does not satisfy the original inequality, contradicting our supposition. Therefore, the limit does not exist.

3) Prove directly from the definition that
$$ \lim_{x \to 0} \frac{1}{\sqrt{1+ \frac{1}{x^2}}} =0
$$

Proof.  Show that $$\fa \epsilon >0, \ex \delta >0, \fa x, 0 < |x - 0| < \delta \implies \left|\frac{1}{\sqrt{1+ \frac{1}{x^2}}} - 0\right| < \epsilon$$
Let $\epsilon > 0$. Choose $\delta = \epsilon$
$$
\begin{align*}
 0 < |x - 0| < \delta &\rightarrow |x| < \epsilon \mbox{ and } 0 < |x|\\
 &\rightarrow |x|^2 < \epsilon^2 \mbox{ and } 0 < |x|^2 \tag{By Lemma 1i}\\
 &\rightarrow 0 < x^2 < \epsilon^2 \tag{Since $|x| = \sqrt{x^2}$}\\
&\rightarrow \frac{1}{\epsilon^2} < \frac{1}{x^2} \tag{Since $x^2 > 0$}\\
&\rightarrow \frac{1}{\epsilon^2} < \frac{1}{x^2} + 1\\
&\rightarrow \left(\frac{1}{\epsilon}\right)^2 < \frac{1}{x^2} + 1\\
&\rightarrow \frac{1}{\epsilon} < \sqrt{\frac{1}{x^2} + 1}\\
&\rightarrow \frac{1}{\sqrt{\frac{1}{x^2} + 1}} < \epsilon\\
&\rightarrow \left|\frac{1}{\sqrt{(1 + \frac{1}{x^2})}} - 0\right| < \epsilon \tag{Since $x^2 > 0$}\\
\end{align*}
$$
