## Q1)

Define the function $g(x) = x - f(x)$

By theorem 6-1, $g$ is continuous on $[a, b]$ since both the functions $f$ and $x$ are continuous on $[a, b]$

We consider 3 cases,
If $g(a) = 0$, then $f(a) = a$ and we are done.

If $g(b) = 0$, then $f(b) = b$ and we are done.

If $g(a) < 0 < g(b)$, then by Theorem 7-1, there exists $x \in [a, b]$ such that $g(x) = 0$ implying that $f(x) = x$.

Thus, there exists $x \in [a, b]$ such that $f(x) = x$.

## Q2)

Base case: $x \in [a_1, b_1]$
let $x = a_1$
$a_1$ is clearly in this set, so $[a_1, b_1]$ is non-empty.

Induction step:
$\ex x \in [a_k, b_k] \implies \ex x \in [a_{k+1}, b_{k+1}]$

Since $I_k \supseteq I_{k+1}$,
$a_k \leq a_{k+1}$
$b_{k+1} \leq b_k$

By induction hypothesis, $[a_k, b_k]$ is non-empty.

Consider the sets
$A = [a_k, a_{k+1}]$
$B = [b_{k+1}, b_k]$
which are non-empty because $a_k \in A$ and $b_k \in B$.

Every element in $B$ bounds above $A$
So by P13, there exists a supremum. We let, $\alpha = \sup(A)$.

$a_{k+1} \leq \alpha$ by definition of supremum

$\alpha \leq b_{k+1}$ by definition of supremum

Therefore there exists an $x$ such that, $x \in [a_{k+1}, b_{k+1}]$

And hence, there exists an $x$ such that, $x \in [a_n, b_n]$

## Q3)

We will consider the function defined on the domain $[0, 2\pi] \subset \R$.

Define the function $f: [0, 2 \pi] \to [0, 2\pi]$ on $\theta$ by
$$f(\theta) = \sqrt{(2 \theta \cos(\theta) - 1)^2 + (2 \theta \sin (\theta))^2}$$
Recall that this is the distance function between an arbitrary point and (1, 0) in polar coordinates. It should be noted that, the domain and codomain may be extended to achieve the same result. We need only discover that such a point that satisfies the condition exists.

By theorem 6-1, $f$ is continuous on $[0, 2 \pi]$. Also, $f(0) = 1 < 5/2 < (4\pi - 1) = f(2\pi)$.

Then by Theorem 7-1, such a $\theta$ exists in $[0, 2\pi]$ where $f(\theta) = 5/2$.

This implies that there exists a point on the spiral whose distance from the point with cartesian  
coordinates (1, 0) is exactly $5/2$.

## Q4)

We want to show there is $x \in [a, b]$ with $f(x) = 0$.

Suppose the algorithm does not stop, because if it did, then we are done$$\alpha \in \bigcap_{n}I_n$$Problem 2 shows that there is such an $\alpha$. So it suffices to show that $f(\alpha) = 0$.

Let $i \in \N$ such that $i \leq n$,
If $f(m_i) > 0$, let $a_i = a_{i-1}$ and $b_i = m_i$
If $f(m_i) < 0$, let $a_i = m_i$ and  $b_i = b_{i-1}$

Remark that, $f(a_n) < 0 < f(b_n)$.
By P10, we will derive a contradiction that shows $f(\alpha) = 0$

Suppose $f(\alpha) < 0$,
$f$ is continuous at $\alpha$, so there is a $\delta$ such that for all $y \in [a_n, b_n]$
$$|y - \alpha| < \delta \implies f(y) < 0$$
it follows that $a_n$ must work since $f(a_n) < 0$
Hence $|a_n - \alpha| < \delta$

or equivalently, $|\alpha - a_n| < \delta$

Since $a_n \leq \alpha \leq b_n$,
$$|\alpha - a_n| \leq |b_n - a_n| = \left|\frac{(b - a)}{2^n}\right|$$
And since $\alpha$ is in the intersection of $I_n$, there is a sufficiently large $n$ for which $$|b_n - a_n| = \left|\frac{(b - a)}{2^n}\right| < \delta$$ Then, $$|a_n - \alpha| \leq \left|\frac{(b - a)}{2^n}\right| <\delta$$
Hence, it must be that all $y \in [a_n, b_n]$ satisfies $|y - \alpha| < \delta$, but $f(b_n) > 0$, contradicting $f(y) < 0$.

Similarly, $f(\alpha) > 0$ is not possible.
$f$ is continuous at $\alpha$, so there is a $\delta$ such that for all $y \in [a_n, b_n]$
$$|y - \alpha| < \delta \implies f(y) > 0$$
it follows that $b_n$ must work since $f(b_n) > 0$
Hence $|b_n - \alpha| < \delta$

Since $a_n \leq \alpha \leq b_n$,
$$|b_n - \alpha| \leq |b_n - a_n| = \frac{(b - a)}{2^n}$$
And since $\alpha$ is in the intersection of $I_n$, there is a sufficiently large $n$ for which $$|b_n - a_n| = \left|\frac{(b - a)}{2^n}\right| < \delta$$Then, $$|a_n - \alpha| \leq \left|\frac{(b - a)}{2^n}\right| <\delta$$
Hence, it must be that all $y \in [a_n, b_n]$ satisfies $|y - \alpha| < \delta$, but $f(a_n) < 0$, contradicting $f(y) > 0$.

Hence $f(\alpha) = 0$.

Therefore, there exists $x \in [a, b]$ such that $f(x) = 0$.
