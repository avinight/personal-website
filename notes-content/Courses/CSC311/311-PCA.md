Advantages  
• Visualize data in 2D/3D space.  
• Help with the curse of dimensionality.  
• Eliminate noise or irrelevant information from the data.  
• Extract new, more informative features.  

Limitations  
• Information loss  
• Sensitive to feature scales.  
• Challenging to interpret the meanings of the principal components.  
• Linear transformation

# Questions
1. PCA is a supervised learning technique.
	- **False.** PCA is an **unsupervised** learning technique because it analyzes the structure of the input data (X) without using any target labels (y).
2. Minimizing reconstruction error is equivalent to maximizing the variance of the reconstructions in PCA.
	- **True.** These are two sides of the same coin. Minimizing the distance between the data points and their projections (reconstruction error) mathematically results in maximizing the spread (variance) of the projected points.
3. The principal components are the eigenvectors of the covariance matrix.
	- **True.** The principal components are the directions of maximum variance, which are mathematically derived as the eigenvectors of the data's covariance matrix.
4. The first principal component corresponds to the eigenvector with the smallest eigenvalue of the covariance matrix.
	- **False.** The first principal component corresponds to the eigenvector with the **largest** eigenvalue, indicating the direction of the highest variance.
5. PCA is insensitive to the scaling of features.
	- **False.** PCA is highly sensitive to scaling. If one feature varies from 0 to 1 and another from 0 to 1,000,000, PCA will determine that the second feature holds all the "information" (variance) and ignore the first. Data is usually normalized before PCA.
6. The projection of a vector onto a subspace and the original vector are always orthogonal.
	- **False.** The projection and the original vector are not orthogonal (unless the projection is zero). _Correction:_ The **residual vector** (the difference between the original vector and the projection) is orthogonal to the subspace (and the projection).
7. The principal components form an orthogonal basis.
	- **True.** The principal components are eigenvectors of a symmetric matrix (the covariance matrix), which means they are orthogonal (perpendicular) to each other.
8. If we use all principal components, there will be no information loss.
	- **True.** If you project data onto all available principal components (where k=d), you are simply performing a change of basis (rotating the axes). No data is discarded, so reconstruction is perfect.
9. PCA can handle non-linear relationships in data effectively.
	- **False.** Standard PCA is a **linear** transformation. It looks for straight lines/planes. It fails to capture non-linear structures (like a spiral or a "Swiss roll" shape) efficiently.
## Short Answer
Here is the short answer section rewritten with formal mathematical notation using Markdown and LaTeX.

### Short Answer Questions (MathJax Edition)

1. What are the two equivalent optimization objectives of PCA?
There are two ways to formulate the PCA objective for the first principal component $u_1$:
- Maximize Variance: Find the unit vector $u_1$ that maximizes the variance of the projected data:
    
    $$\max_{u_1} \frac{1}{N} \sum_{n=1}^{N} (u_1^T x_n)^2 \quad \text{subject to } ||u_1|| = 1$$
    
- Minimize Reconstruction Error: Find the unit vector $u_1$ that minimizes the mean squared distance between the data points $x_n$ and their projections:
    $$\min_{u_1} \frac{1}{N} \sum_{n=1}^{N} || x_n - (u_1^T x_n)u_1 ||^2 \quad \text{subject to } ||u_1|| = 1$$
    

2. How do we determine the first principal component in PCA?
We calculate the empirical covariance matrix $\Sigma$ of the centered data:

$$\Sigma = \frac{1}{N} \sum_{n=1}^{N} x_n x_n^T$$

The first principal component is the eigenvector $u_1$ associated with the largest eigenvalue $\lambda_1$ of $\Sigma$. This satisfies the eigenvalue equation:

$$\Sigma u_1 = \lambda_1 u_1$$

3. What is the relationship between a vector and its projection onto a subspace in PCA?

A vector $x$ can be decomposed into its projection onto the subspace ($\hat{x}$) and its orthogonal component ($x_{\perp}$):

$$x = \hat{x} + x_{\perp}$$

Here, the residual vector $x_{\perp}$ represents the information lost (reconstruction error) and is orthogonal to the principal subspace:

$$\hat{x}^T x_{\perp} = 0$$

4. How do we project a vector onto a k-dimensional subspace in PCA?

Given the top $k$ eigenvectors (principal components) $\{u_1, u_2, ..., u_k\}$, the projection (reconstruction) of a vector $x$ back into the original $D$-dimensional space is:

$$\hat{x} = \sum_{j=1}^{k} (x^T u_j)u_j$$

To transform $x$ into the lower-dimensional representation $z \in \mathbb{R}^k$ (the "code"), we compute:

$$z = U_k^T x$$

where $U_k$ is a $D \times k$ matrix containing the top $k$ eigenvectors as columns.

5. Why do we usually center the data before applying PCA?

PCA interprets variance as the spread around the origin. We center the data to ensure the origin coincides with the mean of the data cloud. We define the centered data $x_n$ as:

$$x_n \leftarrow x_n - \mu$$

where $\mu = \frac{1}{N} \sum_{i=1}^N x_i$. If $\mu \neq 0$, the first principal component might merely point from the origin to the center of the data cloud rather than capturing the direction of maximum variance within the cloud.

6. What does the spectral decomposition of the covariance matrix tell us in the context of PCA?

Since the covariance matrix $\Sigma$ is symmetric and positive semi-definite, it can be eigendecomposed as:

$$\Sigma = U \Lambda U^T$$

- **$U$**: An orthogonal matrix whose columns are the eigenvectors $u_i$ (the principal directions).
    
- **$\Lambda$**: A diagonal matrix containing eigenvalues $\lambda_i$, where $\lambda_i$ equals the variance of the data along direction $u_i$. The total variance in the dataset is the trace of $\Lambda$ (sum of eigenvalues).
    

**7. In what situations might PCA not be suitable for dimensionality reduction?**

- **Non-linear Manifolds:** If data lies on a non-linear shape (e.g., $x_2 = x_1^2$), linear PCA cannot capture the relationship efficiently.
    
- **Non-Gaussian Data:** PCA assumes that the principal components (mean and covariance) fully describe the data, which works best for Gaussian distributions.
    
- **Low-Variance Information:** If the "signal" (predictive power for a classification task) is contained in the components with small eigenvalues (low variance), PCA will treat it as noise and discard it.
