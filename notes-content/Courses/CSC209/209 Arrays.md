## What are arrays?
- Arrays allow us to use variables as index 
- unable to change variable name, unable to change value being printed at runtime
- avoid repetition

Accessing arrays
`address of A[i] = address of A + (i * size of one element of A)`

Array Syntax:
`arr[i] is translated to *(arr + i)`

Segmentation fault - address that was accessed is not legal

Iterating over arrays

Write loop condition using “<“ because we can define constant so that when we need to change the code, we don’t miss one
