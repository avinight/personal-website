The end-to-end argument: Don’t implement some function in low-level software layers if higher-level software must help get that function right.

Applications at higher level or endpoints may implement a function completely and correctly. This may lead to minimalist design such as a microkernel to minimize failures in between the communication system.

Layering reduces module interconnection. Layers can be independently tested, designed, and implemented. Processes at any level can invoke only services of levels below. No circular wait or deadlock.

# Question 6
---
Fairness issue in spinlocks with backoff occur when a new thread joins contention when old threads that have waited longer are sleeping. Essentially the new thread skips the line. Ticket locks solve this problem by introducing FIFO ordering with a now_serving variable.

When a thread tries to acquire the lock, it fetch-and-adds a new ticket, then spins until its now serving variable is called.
When a thread releases the lock, it increments the now_serving variable.

When cache updates, it causes coherency traffic to increase.
