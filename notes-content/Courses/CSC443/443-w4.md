Write amplification of LSM tree = log_T(n/p)

- A **run** is a **contiguous sorted sequence of key-value entries** stored as a file (or SSTable) on disk.
- Each run is **immutable** once written.
- Runs exist in **levels** (Level 0, Level 1, …) of the LSM tree.

For scans of range queries,
- The motivation is because we could've read the entire relevant key range from each one of the runs into memory, and do sort-merge
- If we have a very large range query, we don't wanna read too much stuff into memory
- We read just as much as we need at a time
- Why not just do one level at a time, because how do we know we haven't returned a more recent version of a key to the user already.
