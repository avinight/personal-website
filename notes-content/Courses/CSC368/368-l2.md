# Processor pipelines
##### Pipelining
- pipelining improves throughput
- control unit controls instruction datapath
- write back writes the result from the instruction to registers
- max delay constraint clock
##### Single-cycle datapath:
- Fetch, Decode, Execute, Memory, Write Back
- sometimes the instruction is the branch target
	- but it could also be PC + 4
- store instruction doesn't update register, it updates main memory
- the instruction with the longest latency is load instruction
- max delay constraint
##### Temporal parallelism
- pipeline stages must be balanced
- token must pass through all stages of pipeline before it is complete
- stages are divided by pipeline registers
- each stage worsens latency but improves throughput
- limit to how many stages can be added
