# Goals
1. Configure gem5 with different cache configurations, including a Harvard architecture (separate instruction and data caches) and a multi-level hierarchy
2. Sweep a benchmark for different cache parameters, like cache line size, cache capacity, associativity, etc.

Add command-line arguments for the cache size and cache line size. There are a few sweeps you can perform now:
1. Sweep the cache size, keeping cache line size and daxpy's N fixed
2. Sweep the cache line size, keeping the cache size and daxpy's N fixed
3. Sweet the N in daxpy, keeping cache size and cache line size fixed
