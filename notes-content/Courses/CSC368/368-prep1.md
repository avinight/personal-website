#### Goals
1. List key mechanical and electronic computers that lead to the <span style="background:#b1ffff">stored-program</span> computer
2. List the design decisions made by the IBM System/360 and connect them with modern computer systems
3. Explain how an <span style="background:#b1ffff">instruction set architecture</span> enables <span style="background:#b1ffff">inter-model compatibility</span>


## Quiz
1. Match the mechanical computer with its application.

| Pascal calculator     | Tax-related arithmetic            |
| --------------------- | --------------------------------- |
| Difference engine     | Tabulating 6th degree polynomials |
| Analytical engine     | Any                               |
| Differential analyser | Solving differential equations    |

1. A programming language is Turing complete if it can simulate a Turing machine. This means that the language can...
	- read data from memory
	- define symbols whose state change over time
	- **implement any computer algorithm**
1. All general-purpose computers use the stored-program concept.
	- False
2. The IBM System/360 used a general-purpose machine structure, which meant that different models could be compatible with each other despite having different configurations and implementations. In particular, each model used a different number of general-purpose registers compared to other models.
	- False
3. Match the minimum number of bits needed for each representation below.

| decimal                         | 4   |
| ------------------------------- | --- |
| alphanumeric character          | 6   |
| ASCII character                 | 7   |
| Single precision floating point | 32  |

1. What is the main disadvantage of an architecture that uses addressed registers instead of a pushdown stack?
	- The registers are slower
	- **The encoded instructions are larger in size**
