After attending this lecture, you should be able to:

1. Estimate the performance of vectorized code for a vector architecture using the concept of convoys and chimes
2. Apply the process, when necessary, of strip mining to vectorized code
3. Compare and contrast architectural approaches (vector processor, GPU, multimedia extensions) and paradigms (SIMD, SIMT)
4. Explain how a GPU architecture can provide high performance (e.g., floating point operations per second)

For the content on Vector Processors, you can follow directly along in the textbook freely available through the UofT library. Specifically, see Chapter 3, Section 3.7:

Dubois, Michel, Murali Annavaram, and Per Stenström. _Parallel computer organization and design_. Cambridge University Press, 2012. ([library](https://librarysearch.library.utoronto.ca/permalink/01UTORONTO_INST/14bjeso/alma991106941944406196))

For reference material on GPUs, download Appendix C (freely available) from the [companion materials](https://booksite.elsevier.com/9780124077263/appendices.php)
