# Memory Systems
Memory hierarchy
Temporal locality: 
- If you referenced a book recently, you will probably reference it again soon
- The reuse of data within some (usually short) time duration
- If the processor accesses data, it will likely access it again (soon)


Spatial locality:
- If you pulled one book off the shelf, other books on that shelf are also relevant to you
- The use of data that are located closely together
- If the processor accesses data, it will likely access other nearby memory locations

Each memory component has some latency to access
- `t_cache, t_MM, t_HD`

A miss:
- the data requested isn't available

A hit:
- that data requested is available

$$ \text{MissRate} = \frac{\text{Number of misses}}{\text{Number of memory accesses}}$$
$$ \text{HitRate} = \frac{\text{Number of hits}}{\text{Number of memory accesses}}$$
$$ \text{HitRate} = 1 - \text{MissRate}$$
Let `MR_cache, MR_MM` be the miss rates of cache and main memory respectively

Average memory access time
$$AMAT = t_{\text{cache}} + MR_{\text{cache}} (t_{\text{MM}} + MR_{\text{MM}} \times t_{\text{HD}})$$

# Hardware cache

```C
for(int i = 0; i < n - 1; i++) {
	int min_index = i;
	for(int j = i + 1; j < n; j++) {
		if(a[j] < a[min_idx]) {
			min_index = j;
		}
	}

	int temp = a[min_index];
	a[min_index] = a[i];
	a[i] = temp;
}
```

Cache block
- A cache block is a group of words
- The number of words in a cache block is the block size (b)
- The cache capacity (C) contains $B = \frac{C}{b}$ blocks

Cache organization
- Caches are organized into (S) sets. A set consists of one or more blocks
- Each memory address maps to one set in the cache

Direct mapped cache
- Addresses are word-aligned
- Example of direct mapped cache with B = 4
- Mapping: 𝑆𝑒𝑡 = 𝐴𝑑𝑑𝑟𝑒𝑠𝑠 𝑚𝑜𝑑 4

The tag bits
- Many addresses map to a single set
- The tag identifies the memory address of the data contained in the set
- Compare tag from address with tag in cache

The valid bit
- The valid bit indicates whether the data contents are meaningful
- e.g., valid bits are all 0 when a computer turns on

Two accesses that map to the same cache block cause a conflict
- The more recent access evicts the previous one

Caches with a degree of associativity (N) can reduce conflicts
- Direct mapped cache has N = 1
- When N >= 2, addresses that map to the same set can choose one of N blocks

Trade-offs with associativity
- Higher hardware overhead
- What if all blocks are being used? Need a replacement policy


| Organization          | N     | S   |
| --------------------- | ----- | --- |
| Direct-mapped         | 1     | B   |
| N-way set associative | 1<N<B | B/N |
| Fully associative     | B     | 1   |


## Quiz

It is found that the miss rate of an L1 data cache for a biometric workload is 34%. What is the hit rate of the L1 data cache? 
- 66%

Early computer systems had no cache and connected directly with main memory. The access latency, in cycles, for main memory and the hard drive are 100 cycles and 1,000,000 cycles, respectively. The average memory access time is found to be 90,100 cycles. What is the miss rate in main memory? 
- 0.09

Consider a direct-mapped cache that consists of 16 blocks (B = 16). For a 32-bit address, how many bits are needed for the byte offset, set, and tag? Assume that memory addresses are word-aligned, with the size of a word being 4 bytes.
- Byte-offset = 2
- Set = 4
- Tag = 26

In addition to the data, a direct-mapped cache must store...
- tag and valid bits

What must you check to confirm that a memory access has hit in a direct mapped cache?
- Ensure the **tag** of the memory address matches the stored tag in the cache.
- Verify that the **valid bit** of the cache block is set to 1.
