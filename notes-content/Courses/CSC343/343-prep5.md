In how many countries is English spoken?
```sql
SELECT COUNT(DISTINCT c.code) AS english_speaking_countries
FROM world.country c
JOIN world.countrylanguage cl ON c.code = cl.countrycode
WHERE cl.countrylanguage = 'English';
```

How many languages are spoken in Mozambique?
```sql
SELECT COUNT(DISTINCT countrylanguage) AS languages_spoken_in_mozambique
FROM world.countrylanguage
WHERE countrycode = 'MOZ';
```
