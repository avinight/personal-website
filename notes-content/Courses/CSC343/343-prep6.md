A reminder of the schema we are working with:  
  
country(code, name, continent, population)
countrylanguage(countrycode, countrylanguage, isofficial, percentage)

Consider the following query. Which of the following best describes what this query does?

```sql
SELECT DISTINCT name
FROM country
WHERE continent = 'Africa' AND
EXISTS (
    SELECT * FROM countrylanguage L
    WHERE code = L.countrycode AND L.percentage < 1
);
```

- Find all countries in Africa that have a language spoken by more than 1% of the population.
- Find all countries in Africa that have a language spoken by less than 1% of the population.
- Find all countries in Africa that have more than one language spoken.
- Find all countries that have a language spoken by less than 1% of the population where that language is also spoken in a country in Africa.

```sql
INSERT INTO CountryLanguage (countrycode, countrylanguage, isofficial, percentage) VALUES
```

3. How many languages are spoken in Germany now?
```sql
SELECT COUNT(*) AS num_languages
FROM CountryLanguage
WHERE countrycode = 'DEU';
```

4. In how many continents is Arabic spoken now?
```sql
SELECT COUNT(DISTINCT C.continent) AS num_continents
FROM CountryLanguage CL
JOIN Country C ON CL.countrycode = C.code
WHERE CL.countrylanguage = 'Arabic';
```

Remove from the “countrylanguage” table all records of unofficial languages. A language may be official in one
country and unofficial in another. In that case, don’t remove the language entirely, just the information about it
being used in the country where it is unofficial.
```sql
DELETE FROM CountryLanguage
WHERE isofficial = FALSE;
```

5. How many languages are spoken in Africa now?
```sql
SELECT COUNT(DISTINCT CL.countrylanguage) AS num_languages
FROM CountryLanguage CL
JOIN Country C ON CL.countrycode = C.code
WHERE C.continent = 'Africa';
```
