# Formal system

- Completely self-contained, closed under rule set
- Token-token relationship
- Games are an [[Abstraction | abstract]] notion.

Meaning is not a formal property

Rules only care about configuration and type of tokens

Example
- Alphabet is a formal system // cryptography
- Money is a formal system
	- No intrinsic value
	- Relationship of exchange
- Computational software-mind is a formal system
	- Can be realized on different hardware-brain
	- Hardware is irrelevent to the software if i know what the formal system is.
	- Software is subjective experience
	- AI-software and neuroscience-hardware are not the same
	- computer science is abstract -> mind
	- computer engineering is concrete -> brain
	- Minds turn tokens into symbol


## Properties of Formal Systems
Types of tokens
- Medium (halfway) independent, not media (multimedium).
- As long as you can physically distinguish objects, that is all that is needed for a formal system.

Configuration
- Moving according a finite set of rules.

Medium-independence
- The types of tokens don't depend on the medium being used

Formal equivalence 
- Difference between fraudulent simulations and equivalent instances of cognition
1. For each distinct position (configuration), there is exactly one corresponding position (configuration) in other system => one-to-one mapping between the two.
2. A move is legal in one system => also legal in corresponding system.
3. All starting positions correspond => game could be continued in new medium or started again.
- Legal move in one system is legal in another system
- Same formal system
- Is this like [[Quantum entanglement]]?
- Is [[Meaning (philosophy)]] a formal system?
