# Raising Verbs

Raising constructions involve [[DP Movement Raising and Passive#^bc6e7c | movement]] of an argument from an embeded or subordinate clause to a matrix or main clause.

The matrix verbs that allow this are called raising verbs.

"John happened to produce the film"
- produce(i: agent DP, j: theme DP)
- happened(i: Proposition CP), we know this because we can insert an [[Expletives and EPP | expletive]].

[[Infinitivals]] carry no case
Infinitival Clauses cannot easily support a subject, unlike finite clauses
- *It seems the cat to like the food
- It seems that that cat likes the food.

So subject must move to (spec, cp) where it can get case and satisfies EPP.

The Case Filter:
- All arguments DPs need their Case feature checked.

Nominative Case Checking
- Nominative Case on a DP is checked if that DP is in the specifier of a T_-inf that bears [NOM].

If the external argument DP bears [ACC] at D-structure, and doesn't find something to check it, the result is violation of the Case Filter. 

Accusative Case Checking
- Accusative Case on a DP is checked if that DP is a complement of a V or P that bears [ACC]
